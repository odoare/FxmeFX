### New

- FxmeReverb: an algorithmic stereo reverb built on WDL's Freeverb engine.
It has pre-delay, size, damping and width controls for the tail, low and
high cut on the reverb only, mix and output. Switching it off fades the
tail out and clears it. It comes with three factory presets (Small Room,
Wide Hall, Dark Space) and a Pure Data external (fxmereverb~).

- Built to survive bad input, contrary to the WDL's implementation.
NaN or infinite samples and signals louder
than +24 dB are kept out of the tail, and a tail that still goes bad is
cleared instead of ringing on.

### Improved

- Knob value read-outs no longer end in "…" when the value is long.

### For developers

- Every effect's GUI component now has a compact mode for embedding in a
wide, short slot of a host plugin: no title, flat knobs, and all switches and
menus on one line above a single row of knobs. In compact mode the Equalizer
shows its response graph next to one band's controls at a time. Camshaft
uses this mode.

- FxmeTools is no longer a git submodule. JUCE (8.0.12) and FxmeTools are
pinned in cmake/Dependencies.cmake. CMake uses sibling clones
(../JUCE, ../FxmeTools) when they are present, and otherwise downloads
the pinned commits. Release builds configure with -DFXME_USE_SIBLINGS=OFF.
See the README's Prerequisites section.
